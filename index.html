Font Settings
Import mode
A folder holds styles; activate one folder (checkbox) to use it on Apply. The first style in a folder is the folder default (for bubbles whose tag does not match). Click a style name to edit it. Each style's tag is the line prefix that marks a bubble for that style (e.g. []:); the longest matching tag wins.
Style Editing
Tags to skip lines
Separate tags with a new line or ; . If a line starts with one of these tags, the line is SKIPPED (not pasted) but still shown as context.
Lines without a tag
Mode
Paste mode: translator notes, credits and any other line without a tag are pasted too — add their prefixes to Tags to skip lines. Press Save to re-scan the queue.
Page Mark (page separator bar)
Line prefixes shown as a page separator bar (auto-skipped). One entry per line.
Follow tags (style follows the previous prefix)
Bubble prefixes whose style FOLLOWS the previous bubble line (double bubble). Still applied as a separate bubble. One entry per line.

Plugin
Style library
Before each Replace import the current style library is backed up (1 slot). Restore swaps it back in; the library you had becomes the new backup, so pressing Restore again undoes it.
Settings
Import applies the file right away and re-scans the queue; settings missing from the file keep their current value. Before each import the current settings are backed up (1 slot). Restore swaps them back in; pressing Restore again undoes it. Styles are exported separately in Font Settings.
